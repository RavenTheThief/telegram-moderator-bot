# 🛡️ Telegram Moderator Bot & Web Control Panel System

Продуктовый комплекс для авто-модерации супергрупп Telegram с асинхронным ботом на **Aiogram 3**, REST API бэкендом на **FastAPI**, реактивной веб-панелью управления на **React (Vite + Tailwind CSS)** и контейнеризацией **Docker**.

---

## 🌟 Технологический стек

* **Bot Engine:** Python 3.11, `aiogram 3.x` (асинхронный фреймворк).
* **Backend API:** Python `FastAPI` + `Pydantic v2` + `SQLAlchemy 2.0` (Async) + `AsyncPG`.
* **Database:** `PostgreSQL 16` (основная реляционная БД).
* **Cache & Rate Limiter:** `Redis 7` (скользящие окна антифлуда, кэширование капчи).
* **Frontend Dashboard:** `React 18` + `Vite` + `Tailwind CSS` + `Lucide Icons` + `Recharts`.
* **Orchestration:** `Docker` + `docker-compose`.

Файл `.env` уже создан в корне проекта с рабочим токеном бота. При необходимости настройте свои параметры:

```env

REDIS_HOST=redis
REDIS_PORT=6379
```

### 3. Запуск всех сервисов в контейнерах
```bash
docker-compose up -d --build
```

Проверить статус запущенных контейнеров:
```bash
docker-compose ps
```

Просмотр логов бота или бэкенда:
```bash
docker-compose logs -f bot
docker-compose logs -f backend
```

Остановка всех сервисов:
```bash
docker-compose down
```

## 📋 Основной функционал модерации

1. **Строгий запрет работы в ЛС (DM Restriction):**
   * Middleware `ChatTypeMiddleware` мгновенно блокирует все входящие приватные сообщения. Бот работает исключительно внутри Групп и Супергрупп Telegram.
2. **Система Капчи при входе:**
   * Математический пример (например, `4 + 3 = ?`) или кнопка *"🟢 Я не робот"*.
   * Настраиваемый таймаут (от 30 до 300 секунд).
   * Авто-кик или бан при провале/таймауте капчи.
   * Настраиваемое приветствие и правила после успешного прохождения.
3. **Гибкие Контент-фильтры:**
   * **Фильтр ссылок & Белый список доменов:** Разрешение выбранных доменов (по умолчанию `t.me,telegram.me,telegram.dog`) и удаление сторонних ссылок.
   * **Фильтры медиафайлов:** Раздельное отключение GIF, стикеров, голосовых, видео-сообщений (кружочков), аудио, видео и файлов.
   * **Анти-каналы:** Запрет сообщений, отправленных от имени сторонних Telegram-каналов.
   * **Анти-пересылки:** Удаление пересланных сообщений из других чатов.
4. **Антифлуд (Redis Rate Limiting):**
   * Ограничение кол-ва сообщений за временное окно (например, >5 сообщений за 3 сек = мут).
5. **Система Предупреждений (Warns System):**
   * Выдача предупреждений за нарушения.
   * **Настройка максимального количества варнов (от 1 до 10)** через веб-панель.
   * Автоматический мут или бан при достижении лимита.
6. **Дополнительная защита & Чистка:**
   * **Анти-Caps Lock:** Авто-удаление сообщений с высоким процентом заглавных букв.
   * **Авто-чистка системных сообщений:** Удаление сервисных уведомлений *"Пользователь вошел/покинул группу"*, *"Закреплено сообщение"*.
   * **Таймер авто-удаления сообщений бота:** Бот автоматически подчищает свои уведомления через N секунд.
7. **Веб-Панель управления:**
   * **Дашборд:** Графики активности за 7 дней, диаграммы типов нарушений, статистика активных чатов, участников и банов.
   * **Настройки чатов:** Ползунки, свитчеры, выбор режимов капчи, редактирование белого списка доменов.
   * **Стоп-слова & Regex:** Удобный UI-редактор точных слов и регулярных выражений.
   * **Журнал событий:** Полнотекстовый поиск и фильтрация всех логов модерации.
   * **Управление пользователями:** Просмотр нарушителей и снятие наказаний (варнов, мутов, банов) прямо из веб-панели.

## 🚀 Развертывание на VDS/VPS сервере

1. Подключитесь к VPS по SSH:
   ```bash
   ssh root@your_vps_ip
   ```
2. Установите Docker и Docker Compose:
   ```bash
   curl -fsSL https://get.docker.com -o get-docker.sh
   sh get-docker.sh
   ```
3. Клонируйте проект и запустите сборку:
   ```bash
   git clone https://github.com/your-username/telegram-moderator-bot.git
   cd telegram-moderator-bot
   docker-compose up -d --build
   ```
4. Настройте Nginx или Caddy с SSL сертификтом (Let's Encrypt) для домена панели.
